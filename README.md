# UV_Assay_Sao_Tome
Here we present code and data soon to be tied to a publication, "Sex-Specific Ultraviolet radiation tolerance between Drosophila species from São Tomé and Africa: Adaptation across Drosophila yakuba and Drosophila santomea"

The provided R code facilitates the printing of figures, running statistics, and visualizing data. To execute the code, simply specify the path to the directory of the extracted zipped file (the directory where this readme is located) on line 11 [path <- "<add_path>"], making sure to update the placeholder with the actual path.

Ensure that you run the code with the data file "<UV_Zap_Data>" located in the same directory.

Additionally, an Excel file is included, containing trial film numbers to link data with specific trials. The films will be available for download on Zenodo, accompanied by a DOI for association with the final publication. Currently, the DOI is withheld pending review. Approximately 32 hours of experimental films will be included in the dataset.
